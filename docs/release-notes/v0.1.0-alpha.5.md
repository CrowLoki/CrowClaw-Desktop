# CrowClaw v0.1.0-alpha.5

This alpha adds a grouped model picker inside the chat composer, an explicit
non-reasoning choice for GPT-6 Luna, and an independent CrowBot AI connection.
CrowClaw remains Crow's standalone local-first Windows application.

## Included

- Search available models grouped by configured provider/account directly in chat.
- Choose a model-specific reasoning level separately from Provider default.
  Luna's explicit `none` request was accepted by the real membership route;
  CrowClaw supplements that verified option when the account catalog omits it.
- Edit which models appear, show all, and save per-provider visibility locally.
  Hiding models does not delete them or change the current/default selection.
- Distinguish membership, verified free, local, API-credit and unknown-cost
  metadata. Unknown pricing is not presented as free. The picker uses configured
  connections and their returned/cached catalogs, not an invented universal list.
- Connect to a running CrowBot AI local API or hosted endpoint with the user's
  own gateway key. Hosted secrets are protected on the Windows profile, bound to
  the saved endpoint/connection, and excluded from exports and installers.
- Translate complete, correlated CrowBot textual action proposals into the
  existing native validation and approval runtime. The public Chat wire does not
  accept an OpenAI `tools` field; that does not define the original printer
  harness's capability ceiling. A real request returned a valid directory-list
  proposal; the probe did not execute it or touch a printer.

## Verification and boundaries

The release workflow rebuilds and verifies fresh installation and upgrade from
the published Alpha 3 baseline before publishing. Per-user connection and model
availability still depend on the account and supplier service. No shared account,
gateway key, membership grant or owner conversation is bundled.

The CrowBot transport has complete-history, size, image-type, cancellation,
redirect, secret-redaction and terminal-response checks. Proposed actions must
match the offered registry and argument validators; model text is never direct
permission to execute. Failed, malformed or incomplete replies are not silently
retried or replaced by a paid provider.

## Known limitations

- This remains an unsigned alpha with manual upgrades.
- OpenRouter's saved connection remains free-only. Its account quota can block
  inference; this release does not bypass quotas or spend credits. Paid-model
  catalog/routing expansion remains separate unfinished work. The generic
  API-credit label does not establish a paid provider connection or permission
  to charge it.
- CrowBot's broader native voice/media, image-operation, personality, timbre,
  style and device-command bindings have their own contracts and remain
  integration work. The initial chat/action-proposal connection does not claim
  that all original harness functions are implemented. Physical printing is
  never inferred from generation or a model proposal.
- A local CrowBot connection is optional and requires its supplier app/service
  to be running. Its local port can change after restart; rediscover/reconnect.
  CrowClaw's other configured providers do not require that supplier.
- The full desktop workspace, Claude subscription route, image editing, broader
  OpenAI audio/video and God mode remain unfinished.
- One account's accepted Luna `none` request does not prove every model supports
  it or guarantee that future service behavior is unchanged.
