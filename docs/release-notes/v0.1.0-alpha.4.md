# CrowClaw v0.1.0-alpha.4

CrowClaw is an installable Windows desktop AI agent with local-model operation,
persistent conversations and approval-gated actions. This prerelease adds
personal provider connections and richer conversations while preserving existing
Alpha 3 data.

## What is included

- Native memory search, source labels, withdrawal, rebuild, retained-content
  export and optional local semantic retrieval with offline fallback.
- Reviewed evolution proposals with explicit Apply/Reject and guideline history.
- Conversation-owned drafts and model/reasoning choices. Submitted messages retain
  the account, model and reasoning level used for that request.
- Immutable file and image attachment snapshots with type/size limits, previews,
  local PDF rendering assets and storage/export/retention support.
- OpenRouter sign-in using each user's own key and live free-model catalog.
  Free-only routing checks current prices and capabilities before requests.
- ChatGPT plan sign-in, account-specific catalogs and protected, separated
  registrations. Each user's credentials stay on their own Windows profile.
- Optional, separately authorized ChatGPT image generation with explicit action
  approval, native PNG/message storage and preview. Image authorization is linked
  to the selected registration while retaining each OAuth client's own identity.

The installer contains application code and packaged preview assets. It does not
contain a developer's account, tokens, API keys, conversations, model weights or
private test profile. Local operation requires a compatible model endpoint;
online providers require the user's own eligible connection.

## Verification

The Windows release workflow runs source tests and builds the installer, then
tests fresh installation and upgrade from the published Alpha 3 installer on
independent Windows runners before publishing assets.

Native membership tests exercised real catalog access, GPT-6 Luna low/medium/high
responses, approved tool continuation, sign-out/reconnect and restart. The image
journey exercised GPT-6 Luna/low, explicit approval, generation, atomic attachment
storage, preview and complete process restart. Its 2.2 MiB PNG remained readable
after restart. The service returned 1254x1254 pixels for a requested low-quality
1024x1024 image; this result does not prove every size/quality control is honored.

## Known limitations

- This is an alpha prerelease. The installer is not signed with a production
  Windows signing certificate, and upgrades are manual.
- Provider eligibility, available models, quotas and service behavior depend on
  each user's account. One successful account/model test is not universal access.
  The standard Sign in with ChatGPT Responses route and the separate image
  authorization are distinct. An authorization or quota failure is reported;
  the app does not silently switch to a paid API connection.
- Some Chrome configurations show a blocked loopback return page after the native
  sign-in has completed. Check the app's signed-in status; return-page rendering
  remains a known browser-integration limitation.
- Image editing, Claude subscription integration, OpenAI audio/video modalities,
  the broader desktop panel/extension workspace and God mode remain unfinished.
- Source/native tests do not establish every packaged semantic, export/recovery
  or external-network-isolation scenario. The release workflow verifies its
  declared installed journeys; additional scenarios remain development work.
- The app does not install a local model or require another Crow repository.
