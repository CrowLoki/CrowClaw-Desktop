# CrowClaw v0.1.0-alpha.4 candidate

PENDING-BEFORE-TAG: this is an unpublished candidate, not a usable-release claim.

## Intended scope

- Native local conversation, note and explicitly remembered-file search.
- Source/authorship labels, withdrawal, rebuild, retained-content export and
  transactional upgrades preserving existing CrowQuant records.
- Optional explicitly enabled loopback semantic embeddings, with offline keyword
  and CrowQuant fallback when the model server is unavailable.
- Separate application profiles for isolated native verification.
- Native reviewed evolution: task feedback, proposals, two-response comparison,
  explicit Apply/Reject and immutable guideline revision/restore history.
- Optional native ChatGPT plan sign-in and separated protected registrations,
  account-bound model choices and cancellation. Full live-account acceptance is
  pending; this is not a connected-provider release claim.

The installed app does not require another Crow repository or memory service.
Local-model chat still requires a compatible model endpoint. CrowClaw does not
download a model or make a paid service a prerequisite.
