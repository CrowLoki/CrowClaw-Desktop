# CrowClaw v0.1.0-alpha.2

Alpha 2 is scoped to add a local CrowQuant-compatible memory workflow to the standalone CrowClaw Windows desktop application while preserving the verified Alpha 1 agent, persistence, approval, installation, and uninstallation baseline.

## CrowQuant memory scope

- remember user-entered text from CrowClaw's Memory surface;
- persist the source text, metadata, and compressed local vector data in CrowClaw's database;
- query that memory locally and rank relevant stored records;
- retain the stored memory and retrieval behavior across a full application restart;
- run without Python, a paid service, a remote account, a source checkout, or the separate CrowQuant repository.
