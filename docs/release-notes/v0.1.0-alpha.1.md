# CrowClaw v0.1.0-alpha.1

This is the first standalone CrowClaw Windows desktop Alpha. It is built in a new repository and does not replace or modify any existing SRH-HQRE, Orion, CrowMemory, CrowNest, CrowQuant, or earlier CrowClaw work.

The release will list only behavior verified against the packaged installer. Any product-contract gate that remains incomplete at publication will be stated here before tagging.

## Signing and trust

The Alpha is not yet signed with a production Windows code-signing certificate. Windows may display an unknown-publisher warning. Checksums and a machine-readable release manifest are included so the downloaded installer can be verified against the exact release commit.

## Data and models

CrowClaw does not bundle Crow's accounts, research corpus, credentials, or a paid model service. A compatible local model endpoint is required for real model responses unless a future release explicitly states otherwise.

## Alpha limitations

- Optional custom-endpoint API keys are kept only for the running app session; they are not written to CrowClaw's SQLite database.
- A tool approval that is still waiting when CrowClaw exits is closed safely as interrupted on the next launch. Completed conversations, approved-action results, settings, and messages remain durable.
- Silent uninstall preserves CrowClaw user data. The interactive uninstaller provides an optional, unchecked choice to remove the app data.
- Updates are installed manually by running a newer verified installer; automatic update delivery is not included in this Alpha.
