# CrowClaw v0.1.0-alpha.3

Alpha 3 is the next public prerelease of the standalone CrowClaw Windows desktop AI-agent application. This source document is evidence-bound; its workflow tokens are resolved only after the exact tagged commit passes the release workflow.

## Intended Alpha 3 scope

- let the conversational agent propose local CrowQuant `remember_memory` and `search_memory` actions;
- show every proposed CrowQuant read or write in CrowClaw's existing native approval dialog before execution;
- make denied actions non-mutating and return approved tool results to the connected model;
- preserve approved CrowQuant memory and ranked retrieval across a full application restart;
- replace the previous orange accent direction with CrowClaw's supplied crow branding and a black, violet, purple, and magenta desktop theme while preserving the established application flows.

## Signing and trust

This prerelease is expected to remain unsigned with a production Windows code-signing certificate. Windows may display an unknown-publisher warning. After publication, verify the downloaded installer against the workflow-bound SHA-256 value above or the included checksum and machine-readable manifest.

## Known continuing Alpha limitations

- CrowQuant retrieval uses deterministic lexical features. It is not a neural embedding model, and CrowClaw does not claim semantic-embedding behavior.
- A compatible model endpoint is still required for model-backed chat. CrowQuant memory itself remains local and does not require that endpoint.
- Optional custom-endpoint API keys remain session-only and are not written to CrowClaw's SQLite database.
- Updates remain manual: download and run a newer verified installer.
